## Finding disposition

### F-01 — BLOCKER, **confirmed and corrected for new case/refusal state**

A failed switch to a tampered D2 case previously cleared only the main value/graphs but retained earlier D2/bridge energy J, boundary power W, timestamps, previous model and run provenance. The new `clearEvidence()` resets **all** old quantitative/UI/source fields and removes charts, legend, node/rod graph, selection options, old source link, time slider contents and import messages at the **start** of a new case load and on refusal. It prevents old case values from masquerading as observations of the refused selection. Real Chromium refusal regression checks every old field/graph/source is absent; the final `refusal.png` screenshot corroborates that nothing remains in the old panels.

### F-02 — BLOCKER, **confirmed and corrected for asynchronous case ownership**

A pending authentic D1 import could complete after switching to D2 and overwrite D2's readings, including `NaN` J. The new `caseEpoch` and `importEpoch` invalidate all old fetch/import tasks immediately on selection changes; each import captures the immutable selected case and checks both epoch and case object after file read, after hash+numeric parse, and before rendering **or posting an error/success status**. Outdated asynchronous selection responses cannot re-populate old data.

The real Chromium CI regression holds a browser WebCrypto SHA-256 digest until after D2 becomes active, then releases the old D1 CSV verification and asserts D2's model, preview row count and finite energy values remain unchanged. **Important evidence boundary:** To avoid CI depending on an expiring native archive, the browser race is exercised with a **test-only synthetic 1,001-sample D1 CSV** and a correspondingly repinned, intercepted **test-only** catalog/case hash. The actual browser WebCrypto and full native-CSV parser are used, but the synthetic file is **not** an independently authenticated original native output. A separate positive synthetic full-file import is also executed. Chat B's earlier report independently verified all three authentic archived CSV files through the unchanged parser. A new actual-browser *authentic* CSV replay remains optional further assurance and is **not claimed here**.

### F-03 — MAJOR, **confirmed and corrected for structural/channel ownership**

The old schema accepted a valid suffix even if node readings or rod ports belonged to other nodes. The updated same-version `sim_heat.viewer.native_case/1` validator requires the node's named native temperature, body stored energy and boundary power to belong to **that exact named owner**; each body/boundary has its one valid `id.port`, each rod has two uniquely assigned `id.port_a/id.port_b`, and every edge's `from/to` matches the node containing the corresponding Modelica port. Ownerless junction temperature must refer to an actual recorded native rod endpoint within that same junction. Duplicate/phantom/one-sided ports refuse.

Node tests now cover the exact reviewer counterexamples: reversed D1 edge, swapped D2 body K and J, swapped bridge heated/cooled W, wrong/repeated/phantom/one-sided ports, and falsely attributed junction temperature. A valid junction with a measured rod endpoint remains supported. The three original data bundles and source catalog remain byte-identical; a trusted offline adapter still binds authored model connections to original native data. Structural consistency checks **do not independently prove native execution authenticity** or make a repinned arbitrary artifact physically correct.

### F-04 — MINOR, **confirmed and corrected sign-change semantics**

A zero touch `+/0/+` or `−/0/−` is no longer reported as a true reversal. `firstSignChange` requires a later observed **opposite nonzero** sign and reports the two actually saved bracketing timestamps across any zero samples. It never infers the unsampled crossing instant. Node regressions cover same-sign touches, initially zero, `+/0/−`, `−/0/0/+`, and direct `−/+`; the real bridge reversal still brackets **1720–1730 seconds**.
