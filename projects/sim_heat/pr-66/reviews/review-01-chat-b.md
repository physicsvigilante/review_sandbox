## Independent physical challenges and outcomes

**Sign and dimensional conventions — pass for the source-only laws.** For a rod oriented a→b, the reviewed code forms q_ab = G(T_a−T_b), positive a→b, and creates one +q_ab outward port at a and one −q_ab at b ([thermal_graph.py lines 49–59, 104–125](https://github.com/physicsvigilante/sim_heat/blob/563e10eaa3ec9d7433752172e332cb28b9b9fb41/qualification/h1_n5/thermal_graph.py#L49-L125)). This is compatible with positive-into-component Modelica heat ports: a body's C dT/dt = −ΣQ_out, an ownerless ideal junction ΣQ_out = 0, and a maintained boundary's network supply = +ΣQ_out (lines 129–162, 253–270). Units are G [W/K], capacity [J/K], heat [W], rate [K/s]. Flipping physical rod orientation flips the signed q label while leaving the physical node ledger unchanged.

**Source-exact conductance/Pi — pass for enclosure algebra.** RodArea uses exact positive rational kA/L; RodCircular uses exact positive rational k*pi*d²/(4L), with the inherited rigorous two-sided Machin alternating-series Pi bounds. The code multiplies only positive quantities and returns ordered positive G bounds. The trial computes min/max of G_lo ΔT and G_hi ΔT, so a negative ΔT reverses the endpoints correctly ([lines 196–251](https://github.com/physicsvigilante/sim_heat/blob/563e10eaa3ec9d7433752172e332cb28b9b9fb41/qualification/h1_n5/thermal_graph.py#L196-L251)). Static binary64 candidate hex and *physical exact interval* are different representations; the latter must not be misreported as an executed native reading.

**Unknown/unfamiliar steady graph — independent arithmetic, NOT a run of N5.** I constructed a two-boundary/two-junction five-rod bridge with H=410 K, C=300 K and G(H→J1)=1, G(J1→C)=2, G(H→J2)=2, G(J2→C)=1, G(J1→J2)=3 W/K. Independently solving the two ideal-junction equations gives J1=3140/9 K and J2=3250/9 K. The exact oriented rod flows are 550/9, 880/9, 880/9, 550/9 and −110/3 W. The two junction outward sums are exactly zero, hot supply +1430/9 W and cold supply −1430/9 W. A trial **instead guessing** J1=350 K, J2=360 K gives flows 60, 100, 100, 60, −30 W and nonzero junction residuals **+10 W and −10 W**. The network total still sums to zero by paired ports: global structural conservation does NOT establish the assumed trial as an equilibrium state. The N5 source is topology-generic and its explicit residual and qualification flags agree with this distinction, though this new fixture was **not submitted to an N5 execution environment**.

**Mixed transient, reversed circular branch and isolated body — independent arithmetic, NOT a run of N5.** Consider H=410, J=350, B=340, C=300 and isolated I=330 K. Body B capacity 0.75×480=360 J/K, isolated I capacity 0.25×400=100 J/K. Edges: H→J (G=1, q=60 W), J→B (G=2, q=20 W), B→C (G=3, q=120 W), H→B (G=1, q=70 W), plus **B→H circular** with k=100 W/(m K), d=0.02 m, L=1 m: G=π/100 W/K, ΔT=−70 K and q=−7π/10 W (rigorous negative interval). The algebraic junction residual is −40 W, the trial B outflow is 30−7π/10 W, and the formula yields dT_B/dt=−(30−7π/10)/360 K/s; I has outflow/rate zero. H supply is 130+7π/10 W, C supply −120 W, and all node outward contributions sum **identically** to zero. Reversing the circular endpoints to H→B gives q=+7π/10 while preserving node balances. **Important:** because J violates its zero-storage law, B's displayed derivative is a *formal derivative at an inconsistent assumption*, not a physically validated DAE state or time trajectory; N5 labels that limitation correctly at the top level.

**Interval structural caution — pass.** For an uncertain rod q in [lo,hi], its opposite port is [−hi,−lo]. Independently adding these as unrelated intervals gives [lo−hi, hi−lo], generally not exactly [0,0]; the *shared single physical q variable* cancels identically. The code's structural antisymmetry flag is justified by the per-rod incidence check ([lines 163–191](https://github.com/physicsvigilante/sim_heat/blob/563e10eaa3ec9d7433752172e332cb28b9b9fb41/qualification/h1_n5/thermal_graph.py#L163-L191)), **not** by an interval-sum/timestep error certificate. I separately executed Python Decimal probes showing that strings such as '3_50', ' 350 ' and Unicode-digit '٣٥٠' parse to 350. The numeric value remains **exact and positive**, so this is not a demonstrated energy error or hash bypass; the contract currently says “decimal STRING” without specifying canonical ASCII lexical syntax. **Action:** either document intentional Python-Decimal lexical admission, or impose a full-match ASCII numeric grammar and add explicit acceptance/refusal tests for underscores, surrounding whitespace and Unicode digits. This is not a blocker for a source-only, numeric-exact scoped pass. The direct N5 parser itself was **not independently executed**, so the implementation conclusion also rests on the inspected direct Decimal call.

**F-02 — MINOR, conditional educational interpretation.** [thermal_graph.py lines 253–283](https://github.com/physicsvigilante/sim_heat/blob/563e10eaa3ec9d7433752172e332cb28b9b9fb41/qualification/h1_n5/thermal_graph.py#L253-L283) reports body trial dT/dt even when a storage-free junction has a definitely nonzero residual. This is mathematically the **formal RHS under user-guessed temperatures**, not a valid DAE-consistent instantaneous physical state. Existing stage/interpretation strings and junctionEquilibriumProved=false make this distinction explicit; **no false solver-success claim is observed**. For a future teacher UI, prominently show “junction-inconsistent assumption; derived body rates are conditional”, or add a summary consistency status, so per-node rates cannot be cherry-picked as an actual solution. A regression should assert nonzero junction residuals preserve the user temperatures and never produce “solved/valid state” status.

All corresponding N5 flags are FALSE ([lines 62–78](https://github.com/physicsvigilante/sim_heat/blob/563e10eaa3ec9d7433752172e332cb28b9b9fb41/qualification/h1_n5/thermal_graph.py#L62-L78)).
