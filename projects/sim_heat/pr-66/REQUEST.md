## What the checker actually does

Input is the same exact raw physical source facts (with caller-supplied matching SHA) admitted by independently reviewed N4. A fresh N4 static physical candidate (exact source rational C, G, circular A and original 0.64 ULP source-physical budget) is required; it is **not adopted** as a native reference. `assemble(raw,expected_sha256)` creates equations on arbitrary supported physical graphs rather than hardcoded apparatus topology.

For every oriented conductor `a→b`, defines **positive forward** `q_ab=G(T_a−T_b)`, G a *source-exact rational interval*, not a value calculated from the old float reference or a native trace. Its two ends contribute `+q_ab` and `−q_ab` to outward node heat flow; each rod cancels algebraically. Every body has `C*dT/dt=−Σ(outward q)`, every storage-free junction must satisfy `Σ(outward q)=0`, and every fixed-temperature boundary has prescribed T with outward heat supply `Σ(outward q)`. Parallel rod ports remain individually tracked. Isolated body C and zero flux are permitted; open ownerless ports are refused by N4.

`evaluate_trial(raw,...,temperatures={...})` takes one **positive finite exact Kelvin decimal STRING for every node** (including junction and boundary nodes). It REFUSES omitted/extra or nontext values, nonfinite/exponent bombs, negative/zero Kelvin and fixed-boundary mismatches, and computes **interval** signed rod flows, instantaneous body `dT/dt`, algebraic junction residuals, and fixed-boundary supply. **A trial is a USER ASSUMPTION, not a solution**: it never determines node temperatures, enforces equilibrium by fitting, integrates an ODE, produces a MAT file, independently verifies source authority or certifies a time trajectory. Nonzero junction residuals remain visible. Structural rod antisymmetry is not the same as a global integrated numerical conservation certificate.

Schemas `sim_heat.h1_n5.thermal_graph_balance_candidate/1` and `sim_heat.h1_n5.user_trial_snapshot/1` explicitly keep **all** native/reference/full-grid/source/owner/generality qualification flags FALSE. The purpose is a reusable future LLM-authorable/teacher-inspectable physical interface; the current module does not create a teacher-facing viewer or dynamic time solver.
