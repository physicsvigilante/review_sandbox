**Code:** [scenario_comparisons.py `_verify_authored_check` / `_run_record`](https://github.com/physicsvigilante/emfeeld/blob/fb16a233fb73d7e749e08029c848b4b99c5158a7/src/emfeeld/scenario_comparisons.py#L196-L324), [existing native predicate `observations._comparison`](https://github.com/physicsvigilante/emfeeld/blob/fb16a233fb73d7e749e08029c848b4b99c5158a7/src/emfeeld/observations.py#L141-L154), [native input re-lowering](https://github.com/physicsvigilante/emfeeld/blob/fb16a233fb73d7e749e08029c848b4b99c5158a7/src/emfeeld/model_runs.py#L196-L223).

The new preflight does not accept the mere presence of a truthy or literal `passed=true`. For **every saved native result** it requires either (a) no check where the captured native request has no expectation, or (b) exactly `passed`, `expected_value`, `atol`, `rtol`, `criterion`, `meaning`, with `passed is True` and an exact native-emission match to the re-derived receipt. The request's expectation is tied to the original `investigation.json` via `model_runs.inspect_run` and deterministic re-lowering; the saved actual value is used only as the predicate operand. The existing **Decimal-backed componentwise** comparison is re-used: for each component **`abs(actual - expected) <= atol + rtol * abs(expected)`**, with nonnegative authored tolerances. No source field or particle trajectory is re-evaluated.

**Primary independent reproduction:** generate genuinely complete, checked static native LEFT/RIGHT runs of distinct revisions of one model, with field at `[0.3,0.2,0.1]`, expectation `[0,0,0]`, `atol=100`, `rtol=0`, and genuine `check.passed=true`. Both original signed field comparisons and inspections were **complete**. Copy only RIGHT; change its saved native field vector to **`[200,200,200]`**, recompute the saved magnitude to **`sqrt(120000)`**, leave the genuine *literal true* check and original pinned request/run.json unchanged; independently re-seal the file inventory.
