## Contract/meaning to challenge

The public opt-in verification CLI has two stages:

1. `freeze QUESTION.json --output NEW_LOCK`: strict UTF-8 JSON admission, bounded raw bytes, duplicate-key/unknown-key/invalid origin rejection, stores unmodified `question.json` plus `receipt.json` with raw SHA256, source-origin **declared but not authenticated**, exact requested observation IDs. Unsupported source requirements and unresolved information are preserved as original question data, not silently rewritten.
2. `assess LOCK --packet AUTHOR_PACKET.json --output NEW_ATTEMPT`: verifies frozen source bytes/receipt; rejects unresolved or unsupported requirements **before physics or writes**; uses existing native `packet_from_dict` strict validation and unchanged `run_packet` to compute all explicit requested observations. Exact set of IDs, native type and quantity, SI unit, static world points, potential-difference ordered endpoints, particle/sample index and actual saved physical time are bound to the frozen request. No embedded authored answer `expectation` may be placed in simulation packet. Supports only existing static and saved-index trajectory measurements, not event/nearest-time requests. Saves unchanged source/packet bytes, native report, separate complete/incomplete assessment and pending/final markers in fresh output. Does not rewrite original input or existing evidence.
3. The assessment's *success* means only **all declared native measurements were returned `ok` at the required unit and context**. A domain error, `no_event`, unsupported physics, absent observation, failed native condition, wrong unit/time/type/quantity or data drift cannot become a solved question. The labels `interpretation_fidelity=not_verified`, `independent_physics_correctness=not_evaluated`, `educational_usefulness=not_evaluated` and `textbook_answer_completeness=not_evaluated` are separate and never upgraded because the engine executed.
4. The local receipt is **not an authenticated timestamp** and the declared source origin is untrusted. A full malicious rewrite of both question and unkeyed receipt could re-seal it; a credible true prospective trial still requires a separately authored unseen source and independent reference judge after the source-first lock.
