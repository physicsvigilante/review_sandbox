## Findings and bounded corrections

**F1 — REQUESTED CHANGE, visualization semantics (new `src/emfeeld/wire_view.py:117–126`).** [Issue #60](https://github.com/physicsvigilante/emfeeld/issues/60) requires that students **see an oriented circulation loop**. `wire_view.py` draws a blue **unmarked polyline** via `pv.lines_from_points`, not a direction-marked loop. The only tangential arrow glyphs are the **green physical B directions**, which correctly reverse with I and disappear at I=0; those **cannot** represent the positive circulation orientation `e1 × e2 = u`, which must be fixed even for negative or zero current. The actual independent negative/zero native screenshots confirm there is no blue orientation indicator. Consequently the viewer's label “Blue: oriented Ampere circle” cannot visually disambiguate the fixed loop orientation from the signed B direction. **Fix:** add one clearly distinct, labeled blue loop-tangent arrowhead/positive circulation marker sourced from renderer-neutral `tangent_unit`, persistent for I>0, I<0 and I=0. Keep green B arrows, the physical integral and the schematic separation intact. Add native negative and zero scene assertions/captures showing the **blue orientation is unchanged** while green arrows reverse or vanish. This is a narrow display correction; **not** a reason to rewrite the analytic solver.

**F2 — advisory input-hardening (new `src/emfeeld/wire_magnetism.py:133–135`).** The *direct Python probe API* silently accepts a mixed Boolean and numeric vector: `magnetic_field(WireState(), [True,0,0])` returns a nonzero field at (1,0,0), because `np.asarray` promotes the Boolean to an integer before the dtype-kind check. Full-Boolean arrays refuse, and crucially **authored JSON Booleans already refuse correctly**. This is **not** an authored-JSON gate failure, but pre-coercion Boolean validation and one nested/mixed regression test are recommended while modifying the narrow feature. Do not conflate it with failed on-axis/nonfinite/underflow refusals: those passed.
