## Motivation and tested physical design

The prior engine supports isolated v7 circular, v8 triangular and v9 convex quadrilateral dielectric bodies, plus bounded *single* glass with external mirrors/blockers v10–v13. It cannot represent two distinct glass bodies within the same canonical physical scene. v14 reuses the exact polygon component, 1–4 `SingleRay` emitters, up to 2 detectors, and native `Glass` compiled independently for **two disjoint convex quadrilateral regions**. Exterior refractive indices must be explicitly equal. No LLM-prescribed route, custom Snell/Fresnel propagation or modified numerical tolerance. Core source/adapter and native observers are unchanged. The 0.01 mm strict separation is a **reuse of existing admitted geometry clearance**, not independently validated numerical ray-intersection precision.

One synthetic fully specified request `examples/two-separated-glass.json`: source x=-200/y=10 mm directed +10°, G1 x0–150 mm nInside1.5, G2 x200–350 mm nInside1.3, equal nOutside1, Fresnel-off approximation, D1 x500. No original textbook source was interpreted and no heldout LLM answer was tested. The source README and [physical limits](https://github.com/physicsvigilante/opticsim/blob/3c1bcc317689386333c4155ee414f8fa99a1caea/docs/TWO-SEPARATED-DIELECTRICS.md) remain explicit about scope.
