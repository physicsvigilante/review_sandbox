## What is proposed

A **new isolated version-14 native optical arrangement**: `schemaVersion=adapterVersion=14`, `physics.model='two-separated-dielectrics-tracing'`. Admit exactly **two separately authored strictly convex four-vertex finite `polygon-dielectric` regions**, 1–4 `point-source` with **single-ray** emission only, optional 0–2 `ray-detector`; no additional optical elements, other media, beam cones, nesting or arbitrary polygons. Require both exact explicit `outsideIndex` values to be equal; each independently authored `insideIndex` and `partialReflection` is preserved.

There is **no new native ray solver or custom refraction**: Opticsim passes each original polygon to **one separate pinned native `Glass`**, with its existing relative index `insideIndex/outsideIndex`. Pinned PhyDemo selects all intersections, reflections, transmissions and misses. Native interface observers retain their existing per-ID and per-face callback instrumentation; no LLM supplies ray path or inferred image.

**Geometry rule:** use existing v9 `validatePolygonGeometry` for each region independently (strict convexity; 1 mm edges/altitudes; authored sources 0.01 mm from finite face and initial forward vertex; detectors wholly outside and with common separating face), then require a common outward supporting face of one convex polygon with all vertices of the other at least the **existing 0.01 mm clearance**. This is a deliberately conservative admission/SAT certificate, **not** a newly validated physics intersection tolerance or correction to any native borderline error. No silently normalized indices or geometry; mismatched exterior indices, near-touching, crossing, nested or unprovable separation must reject before any native tracing.

Native numerical limits persist: `maxRayDepth<=8`, same 10,000 processed limit/policies and upstream default seed and weak-ray Fresnel cutoffs; full-Fresnel can truncate. Incomplete/stopped/undefined/warning-qualified outcomes must remain explicitly qualified/withheld; conditional image inference for arbitrary two finite bodies stays `unavailable`. This does **not** solve known critical/grazing numerical questions in Issues #21/#23.
