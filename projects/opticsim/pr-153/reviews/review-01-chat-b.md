## 3. P1 — One-interface measured-zero accepts contradictory or incomplete first-event content

**Location:** [witness lines 157–185](https://github.com/physicsvigilante/opticsim/blob/1107014449ac9fb89fce9bdaa93a44052d664b09/scripts/jee-observer-native-witness.mjs#L157-L185), particularly 164–169; compare the independently stricter positive path at [lines 193–218](https://github.com/physicsvigilante/opticsim/blob/1107014449ac9fb89fce9bdaa93a44052d664b09/scripts/jee-observer-native-witness.mjs#L193-L218) and the actual [interface first-event structure](https://github.com/physicsvigilante/opticsim/blob/1107014449ac9fb89fce9bdaa93a44052d664b09/src/planar-media.js#L91-L111).

When `crossings.value===0` and `interactions.value===1`, the current predicate requires only a first-event object with `available/qualified` status, native-observation method and matching `incidentIndex`/`destinationIndex`. It **never checks** `first.value.outcome==='transmission'`, the existence of an actual transmitted branch, agreement with the interface transmitted count, or finite essential event angles/branch directions. The `evaluateObservables` interface-first-event projection checks only that the event value is non-null before assigning `native-observation`; it **does not perform these structural/physical validations** downstream.

**Concrete static counterexample (not an independently executed regression):** start from the test's existing synthetic *completed, hash-matched* native summary; set detector crossings and observed hit count to zero with `events=[]`, keep one emitted ray, one interface interaction and the original indices; then set `interfacesById.I1.first.outcome='transmission'` but `first.branches=[]` and `interfacesById.I1.transmitted=0`. The observation methods remain the accepted native projection labels. This internally contradictory first-event record passes every zero-path predicate and is returned as `native-observed-no-crossing` with **exit code 0**. Likewise, changing the one-event outcome to `total-internal-reflection` without a transmitted branch, or injecting a nonfinite first incident angle, is not independently disqualified by that path.

This is contrary to the requested *one transmitted interaction* admission case and to the requirement that contradictory/unqualified first-event evidence must not be promoted. It also hides a potential discrepancy between the analytically proposed transmitted ray and the native interface outcome. **A measured detector zero still exists**, but the **additional bounded witness classification is unqualified** and must be withheld until first-event provenance is internally consistent.

**Required correction before clearance:**

1. For the one-interaction zero case, require a method-qualified first event with the correct stated medium direction, `outcome:'transmission'`, exactly one usable transmitted branch (allow an additional physically legitimate reflected branch when full Fresnel is enabled), a finite first incidence/transmission angle and a finite transmitted unit direction. Make sure the relevant observed interface counters/branches do not contradict the first event. Preserve a separate legitimate zero-interaction branch whose first event is unavailable/null.
2. Add synthetic completed/hash-matched **refusal regressions** for first event reporting transmission with an absent transmitted branch, contradictory transmitted count, reflected-only/TIR outcome, missing/malformed angle or nonfinite vector; assert `native-evidence-unavailable`, null accepted hit and nonzero exit. Add a legitimate full-Fresnel transmitted-plus-reflected control so the fix does not overreject actual branches. Do not silently substitute analytically predicted angles or ray histories.
3. Keep the valid transmitted-miss and zero-interface-miss tests, positive actual native arrival test, stale/incomplete/zero-emission/count-mismatch refusals and fixed-angle mismatch reason intact. Re-run exact-head checks and obtain a fresh independent review of the **new SHA/tree**.

**Severity:** **P1 / release-gating** for this specifically advertised evidence-integrity contract. **P0: none.** This is a source-gate counterexample, **not** evidence that the real pinned native zero controls themselves contain bad events.
