The physical actual 3D spheres are drawn as **XY orthographic projections with one metre scale**. The signed inner-surface atlas is **discrete point samples** (24 default rays per cavity, maximum 48) from the released real `inner_surface_charge_density` kernel. θ denotes colatitude from +z and φ longitude from +x towards +y, display labels approximate; the original raw admitted near-unit binary64 3-vector alone defines the real high-precision physical ray. **Never substitute rounded display `unit_normal` for original `input_direction` at the wall.** Whole-face induced Q from native Gauss ledger is a separate quantity; never infer it by summing point tiles. Outer spherical face sigma is uniform in this no-exterior-input regime and grounded outer sigma must be exactly zero. An isolated/grounded switch is **two static equilibrium solutions**, not simulated electron movement, grounding current, or time.
