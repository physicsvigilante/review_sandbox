## Findings and required follow-up

**B1 — REQUIRED, verification blocker: printed PDF pages were not independently visually accessible here.** GitHub's binary PDF bodies (20.7 MB workbook and 9.1 MB notes) could not be fetched in this execution environment; file URL browsing was blocked. The original PDF **Git blobs are byte-identical across base/head**, and existing exact-tree CI artifacts contain the frozen SHA256 declarations (`9dff3c02...e1fbca5d` and `8d0d9b5c...a39b777e460944df44c3f9cffcb68157a60e5`), but I **did not personally hash the raw PDF bytes** or view its twelve printed pages. Developer page-inspection notes do not meet the requested separate-context visual certification. A reviewer with raw PDF access must inspect 12 source pages, diagrams, options, and exact geometry, independently compute both SHA256s, and attach/page-pin that evidence. This is an evidence-access limitation, not a demonstrated source transcription defect.

**B2 — REQUIRED, verification blocker: native released APIs were not executed locally in this reviewer runtime.** I independently derived mathematics and compared actual CI native/reference JSON, browser screens and source code, but the local checkout of the precise HEAD and PDF bytes could not be obtained. The supplied standard-library reproducer has an optional `--repo` mode that asserts original PDFs and cohort metadata. A reviewer with checkout should run the source-pinned native M36b/M36c/M36d/M37b/M40a cases and three additional signed teacher variants without relying solely on existing developer probes; preserve logs. Current CI passing is real but is **not** an independent local test run.

**F3 — MODERATE, browser accessibility finding (inherited released viewer, not newly introduced by PR109).** With JavaScript disabled on mobile, p27 and p26 preserve explanatory banners (p26 also keeps source numeric readout cards), but the diagram, conductor results and density profile are empty. Controls remain visible without a clear `<noscript>` or static alternative. p2 keeps part of the event table but loses dynamic display. Recommend explicit JS-required accessible notice and/or static SVG/text fallback, or document an owner-approved no-JS accessibility exclusion; do not misrepresent empty visuals as accessible physics. Verified with Chromium screenshots and no-JS/mobile logs; JS-on mobile was sound. This is distinct from the main JEE-12 source-evidence blockers.

**F4 — LOW, attribution copy clarity.** Existing p26 browser title calls the **notes illustration** “JEE original p26”, while the JSON correctly says a teaching note is not itself an official JEE exam paper. Prefer `Notes p26 Illustration 1 — original printed source` to prevent official-exam ambiguity. This is existing viewer copy, not a changed PR109 module.
